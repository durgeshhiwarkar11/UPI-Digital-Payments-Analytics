# UPI & Digital Payments Analytics Dashboard

## Project Overview
This project presents an interactive Power BI dashboard designed to analyze UPI and digital payment transactions. It provides insights into transaction trends, payment performance, customer behavior, and digital payment patterns.

## Objectives
- Analyze UPI transaction performance.
- Track transaction volume and total transaction value.
- Identify monthly and yearly transaction trends.
- Understand customer payment behavior.
- Monitor successful and failed transactions.
- Support data-driven business decisions.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
- Data Modeling
- Data Visualization

## Key Performance Indicators (KPIs)
- Total Transaction Amount
- Total Transactions
- Total Customers
- Average Transaction Value
- Successful Transactions
- Failed Transactions
- Transaction Success Rate

## Dashboard Features
- Interactive KPI cards
- Monthly transaction trend analysis
- Payment method analysis
- Customer transaction analysis
- Dynamic slicers and filters
- Transaction performance insights

## How to Use
1. Download the `.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Refresh the data source if required.
4. Explore the interactive dashboard using slicers and filters.

## Business Value
This dashboard helps analyze digital payment performance, identify transaction patterns, and understand customer payment behavior.
